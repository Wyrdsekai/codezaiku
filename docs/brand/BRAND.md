# The CodeZaiku marks

The emblem, the wordmark and the name **CodeZaiku** (コード細工) identify this project. They are
shipped here so the README, a fork or a mirror can show the project's own mark without depending on
codezaiku.org being up.

**They are not covered by the Apache License** that covers the code. You may use them to refer to
CodeZaiku — a link, a "built with", a screenshot, a package that wraps it — and you may not use them,
or a confusingly similar mark or name, to identify a different project or product. A fork that
changes what CodeZaiku does should take its own name and mark.

| file | use |
|---|---|
| `emblem.svg`, `emblem-colour.svg` | the mark alone, monochrome and in colour |
| `emblem-512.png`, `emblem-dark-512.png` | the mark rasterised, for light and dark backgrounds |
| `wordmark.svg` | the name, set in CMU Serif Italic (SIL Open Font License) |
| `logo-light.png`, `logo-dark.png` | emblem and wordmark together |
| `favicon.svg`, `favicon.ico`, `icon-192.png`, `icon-512.png` | icons |

The source artwork and the generator that produces these files are not part of the public tree.
